# Urbaniac Website

Responsive bilingual (English / Bahasa Indonesia) static website for GitHub Pages.

## Included
- `index.html` — bilingual page structure (`Urbaniac — A Discord-Based Urban Life RPG`)
- `terms/index.html` — Terms of Service (`/terms/`)
- `privacy/index.html` — Privacy Policy (`/privacy/`)
- `style.css` — low-glare Midnight Slate × Urbaniac brand palette (`#121824`, `#1D2738`, `#28354A`, `#FFD166`, `#79B85C`), `Plus Jakarta Sans` + `JetBrains Mono`, WCAG AA contrast, and `prefers-reduced-motion` support
- `script.js` — accessible mobile drawer, `localStorage`-persisted EN/ID switch, interactive 5-stage city progression tabs, and dynamic footer year
- `assets/banner.jpg` — official Urbaniac panoramic key art (`1024×384`)
- `assets/icon.png` — official Urbaniac favicon

## Publish with GitHub Pages
1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select branch `main` and folder `/docs` (or `/ (root)` if hosted in a dedicated website repo), then save.
4. Wait for the published URL shown in the Pages settings.

This is a static informational website. It does not include a player login, live game dashboard, database, or ticketing system.
